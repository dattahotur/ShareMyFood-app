# 🍱 ShareMyFood

A MERN Stack web application designed to reduce food waste by allowing individuals, restaurants, and organizations to sell or donate surplus food to people and NGOs at affordable prices.

---

## 🚀 Features

* 👤 User Authentication & Authorization
* 🍴 Food Listing & Management
* ❤️ Food Donation System
* 🏪 Restaurant Food Selling
* 🤝 NGO Food Collection Support
* 📱 Responsive User Interface
* 🔍 Easy Food Browsing
* 📦 Real-Time Data Management

---

## 🛠️ Tech Stack

### Frontend

* React.js
* HTML5
* CSS3
* JavaScript

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Tools & Platforms

* Git & GitHub

---

## 📸 Project Overview

ShareMyFood aims to create a sustainable platform that helps reduce food wastage while supporting communities in need. Users can share, donate, or sell excess food efficiently through a clean and user-friendly interface.

---

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/sharemyfood.git
```

### Navigate to Project Folder

```bash
cd sharemyfood
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm start
```
